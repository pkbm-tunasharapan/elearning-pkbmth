Cara memasang

  1. Ketuk Unduh APK dan tunggu sampai selesai.
  2. Buka berkas yang diunduh (dari notifikasi atau folder Download).
  3. Bila diminta, izinkan “Instal aplikasi dari sumber ini” untuk Chrome.
  4. Ketuk Perbarui / Instal. Aplikasi lama tertimpa; akun dan data tetap aman.

Bila muncul “Aplikasi tidak terinstal”, coba unduh versi HP lama (32-bit). Setelah terpasang, aplikasi akan memberi tahu sendiri setiap ada versi baru.
